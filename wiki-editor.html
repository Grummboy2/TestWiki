Edit the Wiki

Use the visual editor on your own computer to change pages, organize the menu, and adjust the colors. It saves directly to the TestWiki folder without a browser folder picker.

Open the repository

#Open the local editor

  1. Double-click Start-Wiki-Editor.bat in your TestWiki folder. Or, open a terminal in that folder and run node tools/visual-editor-server.js.
  2. Open http://127.0.0.1:8765/tools/visual-editor/ in a desktop browser.
  3. The editor connects to the TestWiki folder automatically. You do not need to grant browser file access or choose a folder.
  4. Keep the terminal running while using the editor. Stop the local server with Ctrl+C when you are finished.

#Edit pages visually

Choose a page in the editor and select Start editing. Click text in the preview to edit it directly; use the formatting buttons for emphasis and lists. Select Extra options: On when you want drag handles and ⋯ menus to appear. Button-style links in action rows can be dragged and reordered individually. A block's menu can select all of its text for replacement, add paragraphs, headings, or lists; duplicate or delete a block; move it up or down; change link addresses; and replace images or edit their descriptions. Save the page to write it into this local TestWiki folder.

#Add pages, move links, and change colors

Use the editor's page and menu controls instead of writing HTML or changing the settings file yourself. New pages start from the site's existing page template and can be added to a menu group. Reorder, rename, or regroup menu links, and choose light- and dark-mode accent and home-banner colors using color pickers.

#Choose a Minecraft edition

The Wiki opens with a Bedrock-or-Java choice. Bedrock opens the current guides; Java opens a separate starter page for future Java-specific content. The edition choice is remembered on this device and can be changed from the Bedrock overview or by choosing Change edition.

#What "only me" means

This is a local editor, not a public control panel. It has no website login and cannot publish commits. Its local server listens only on this computer and only saves Wiki pages and settings. Other website visitors cannot use it to change your computer or the live Wiki. It does not distinguish between Windows accounts on this same computer, so stop the server when you finish editing. Publish local edits to the website later using your normal GitHub account and repository access.

#Browser and safety

Use a desktop browser such as Microsoft Edge or Google Chrome. The editor saves directly into the local TestWiki folder through its loopback-only server. It does not ask for a password, GitHub token, account credentials, or browser folder permissions.

Keep the site server running only while you use the editor. It listens on 127.0.0.1 (this computer), serves Wiki pages and assets, and accepts save requests only from this local editor for approved Wiki files. Changes remain local until you publish them through GitHub.
