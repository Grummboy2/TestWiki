Install

Get DragonMounts 2 running in a Bedrock world, update from an older build, and fix the usual problems.

#Before you start

  • This guide covers the Bedrock Edition add-on. Java Edition has its own, separate Dragon Mounts mods.
  • Back up your world first. In Minecraft, edit the world and choose Export World.
  • Keep Minecraft up to date. Update 2.0 Drop 1 targets Server API 2.10.0.

#Updating from an older build

The add-on ID changed to dragonmounts2 in this update, so do not just copy the new files over the old ones.

  1. Back up your world.
  2. Edit the world, open Add-ons, and remove the old DragonMounts packs.
  3. Import the new add-on file.
  4. Turn on both the new Behavior Pack and Resource Pack.
  5. Load the world and check that your dragons are still there.

#Troubleshooting

I can't find the add-on in my world's settings

Make sure Minecraft showed a message that the import finished. If it did not, open the file again, or open the .mcpack files one at a time. Then fully close and reopen Minecraft, and edit your world again.

Dragons or items are missing

Both packs must be on. With only the Resource Pack you get textures but no dragons. With only the Behavior Pack you get the features without the visuals. Open your world's Add-ons list and check that both DragonMounts 2 packs are active.

Things look broken after updating

The add-on ID changed to dragonmounts2. Old packs and new packs can end up active together. Remove the old packs from the world, then apply the new ones. See Updating from an older build.

It works for me but not on my server or Realm

Packs have to be applied to the world that is actually running, not just the copy on your device. Apply both DragonMounts 2 packs to the server's world, then restart it.

A feature does not behave as described

Check that your Minecraft version is up to date, because Update 2.0 Drop 1 targets Server API 2.10.0. Then compare against the changelog. If it is still wrong, ask on Discord or report it.
